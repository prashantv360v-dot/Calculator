# Simple JavaScript Calculator

A modern, responsive, and fully functional web-based calculator build useing **HTML**, **CSS** and **JAVASCRIPT**.

## Features🚀

* **Basic Arithmatic operations:** Addition (+), Subtraction (-), Multiplication(*), and Division (/).
* **Percentage Calculation:** Easily calculate percentages (e.g., '50 + 10% = 55').
* **Clear & Delete:** Use 'AC' (All Clear) to reset the screen and 'Del' (Delete) to remove the last entered character.
* **Responsive Design:** Adspts smoothly across various screen size (mobile, tablet and desktop).
* **Error Handling:** Safely hanles invalid mathematical expressions by displaying an "Error message instead of crashing.

  ---
  ## 🛠️ Tech Stack

* *HTML5:* For structuring the calculator interface.
* *CSS3:* For styling, Flexbox/Grid layouts, and modern aesthetics.
* *JavaScript (ES6):* For core calculation logic, DOM manipulation, and event handling.
